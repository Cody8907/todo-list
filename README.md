# 📝 My To-Do List

A simple, clean to-do list web app built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ Add, complete, edit (double-click), and delete tasks
- 🔍 Filter tasks: All / Active / Completed
- 💾 Tasks persist in your browser via `localStorage`
- 🧹 "Clear completed" button and live task counter
- 📱 Responsive design that works on mobile

## Run it locally

No build step or dependencies needed. Just open `index.html` in your browser, or serve it:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Tech stack

- HTML5, CSS3 (flexbox, CSS variables, animations)
- Vanilla JavaScript (no frameworks)
